## 📰 Daily Dribble — Solo Project Replacement  
*A newsletter sign‑up section for a fictional basketball blog.*

---

### 🎯 Project Goal  
Create a **single newsletter sign‑up component** that could appear on a landing page for a basketball news site called **Daily Dribble**.

The component must be centered on the page, visually balanced, and use the layout, spacing, and styling techniques you’ve learned so far.

---

## 📐 Requirements  
Below are **all functional and visual requirements** you must meet.  
Every bullet begins with a Guided Link so you can explore any part in more depth if you want.

---

### 🧱 Structure  
- **Newsletter container** — A parent element that holds all content for the component.  
- **Main heading** — A title reading: **“The Daily Dribble Newsletter”**.  
- **Subheading** — A short tagline describing what the newsletter offers (you invent the text).  
- **Email input field** — A single input for the user’s email.  
- **Primary button** — A button labeled **“Subscribe”**.  
- **Secondary button** — A button labeled **“Learn More”**.  
- **Footer note** — A tiny disclaimer text (you invent the text).

---

### 🎨 Styling Requirements  
- **External CSS link** — All styling must come from a linked CSS file.  
- **Fixed width** — The newsletter container must have a defined width.  
- **Block vs inline** — Use at least one inline element and one block‑level element intentionally.  
- **Margins** — Use margin‑top to create vertical spacing between major sections.  
- **Div usage** — Use divs to group related content.  
- **CSS classes** — All styling must be applied via classes, not inline styles.  
- **Spacing between elements** — Add visible spacing between the input, buttons, and text.  
- **Centering with margins** — Center the entire component horizontally.  
- **Centered content** — Center the text inside the component.  
- **Padding** — Apply padding inside the container.  
- **Border** — Add a border around the container.  
- **Border radius** — Round the corners of the container.  
- **Styled button** — Style both buttons so they look intentional and distinct.  
- **Input field fix** — Ensure the input field has consistent padding, border, and width.  
- **Flexbox layout** — Use Flexbox to place the two buttons next to each other.  
- **Centered buttons** — Center the button group horizontally using Flexbox.  
- **Block‑level button rule** — Ensure the buttons are not block‑level elements when placed side‑by‑side.

---

### 🏀 Thematic Requirements  
- **Basketball imagery** — Include at least one basketball‑related visual element (emoji, icon, or image).  
- **Color palette** — Use a palette inspired by basketball (e.g., orange, black, white, hardwood brown).  
- **Tone** — The tagline and footer note should match a fun sports‑newsletter vibe.

---

### 📱 Bonus Challenges (Optional)  
- **Hover states** — Add hover effects to both buttons.  
- **Focus state** — Style the input’s focus state.  
- **Shadow** — Add a subtle shadow to the container.  
- **Responsive width** — Make the container shrink gracefully on small screens.

---

## 🧪 Final Deliverables  
Your finished project must include:

- A single HTML file  
- A single linked CSS file  
- A centered newsletter sign‑up component  
- All requirements above implemented  
- No JavaScript
